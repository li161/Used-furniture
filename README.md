# SECOND·LIFE — 二手家具的第二人生

一个以复古艺术画廊为灵感的沉浸式二手家具宣传页。纯 HTML/CSS/JavaScript，无需构建步骤。

## 本地预览
直接用浏览器打开 `index.html`。

## 交互
- 拖动修复前后滑块，查看家具状态对比
- 在房间场景中拖动沙发，自由调整位置
- 切换沙发配色，预览不同家居氛围

## GitHub Pages
仓库通过 GitHub Actions 自动发布。进入 **Settings → Pages → Build and deployment**，将 Source 设为 **GitHub Actions**。推送到 `main` 后会自动部署。
